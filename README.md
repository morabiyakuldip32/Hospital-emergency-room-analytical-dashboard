Hospital Emergency Room Dashboard 

This Hospital Emergency Room Dashboard is a Power BI data analytics project designed to provide a clear and interactive overview of emergency room performance and patient activity. The dashboard analyzes key metrics such as total patients, average waiting time, patient satisfaction score, admission status, gender, age groups, waiting status, department referrals, patient race, and admission time ranges. It includes interactive filters for year, month, age, race, and gender, allowing users to explore patient data and identify important patterns and trends. This project demonstrates my practical skills in Power BI, data visualization, dashboard design, data analysis, and business intelligence, with a focus on transforming healthcare data into meaningful and easy-to-understand insights.
